# QRPrint Project Structure

```text
/merchant-app       Electron + Express local Windows server
/customer-web       Next.js app deployed to Vercel
/shared-types       TypeScript contracts shared by both apps
/docs               Architecture, setup, install, customer testing, API, and phase guides
/scripts            One-command merchant install scripts for Windows and Unix-like development
/src                Existing interactive prototype and documentation viewer
```
